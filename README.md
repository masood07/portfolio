# Portfolio Website

A responsive portfolio website built with HTML, CSS, and Bootstrap 5.

## Live Preview

Open `index.html` in your browser or use Live Server in VS Code.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.8
- Bootstrap Icons

## Sections

1. **Navbar** - Fixed navigation with logo and links
2. **Hero** - Introduction with profile image
3. **Worked With** - Company logos section
4. **Case Studies** - Project showcases with images
5. **Testimonials** - Client reviews in cards
6. **Recent Work** - Carousel with project cards
7. **Contact Form** - Email, mobile, and message fields
8. **Footer** - Simple footer

## Features

- Responsive design (mobile, tablet, desktop)
- Bootstrap grid system (col-12, col-md-6, etc.)
- Dark theme with custom colors
- Image carousel for recent work
- Contact form

## Bootstrap Classes Used

- `container` - Centers content with padding
- `row` - Creates horizontal groups
- `col-12` - Full width on mobile
- `col-md-6` - Half width on tablet and up
- `d-flex` - Flexbox container
- `justify-content-center` - Center items
- `align-items-center` - Vertical center
- `text-center` - Center text
- `text-light` - White text
- `p-5` - Padding on all sides
- `mt-5` - Margin top
- `mb-4` - Margin bottom
- `g-4` - Gap between grid items

## How to Edit

1. Open `index.html` to change content
2. Open `style.css` to change styles
3. Add images to `Assets/` folder

## Responsive Breakpoints

- Mobile: Less than 768px
- Tablet/Desktop: 768px and above
